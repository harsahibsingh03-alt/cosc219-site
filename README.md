Lab 3 – Responsive Layout

I improved the website to work on mobile, tablet, and desktop screen sizes.

Breakpoints

38rem (608px): The navigation changes from a vertical layout to a horizontal layout. The Projects page changes from one card column to two columns. The About page changes from one column to two columns, with a wider main section and narrower sidebar.

58rem (928px): The Projects page changes from two card columns to three columns.

I chose these breakpoints to provide enough space for the content as the screen becomes wider. The layout starts with one column for smaller screens.

Flexbox and Grid

I used Flexbox for the navigation because it makes it easier to arrange the site heading and navigation links, control spacing, and wrap links when needed.

I used CSS Grid for the project cards and the About page because Grid makes it easier to create responsive columns. The About page uses a wider content column and a narrower sidebar.

Responsive Images and Accessibility

I used max-width: 100% and height: auto to make images responsive while maintaining their proportions.

I also included viewport meta tags, image alternative text, semantic HTML, and visible keyboard focus styles.
